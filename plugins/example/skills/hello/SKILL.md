# Hello

When this skill is invoked, greet the user and confirm the plugin is installed correctly:

1. Say hello and mention the skill was loaded from the `example` plugin in the `zamboni-skills` marketplace.
2. List the tools available to you in one short sentence.

Replace this skill with your first real skill: each skill lives in its own
folder under `skills/` with a `SKILL.md` describing when to trigger and what
to do. Supporting files (scripts, references) can sit alongside `SKILL.md`.
